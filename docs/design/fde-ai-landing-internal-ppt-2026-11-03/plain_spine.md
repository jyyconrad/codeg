# 白话叙事页脊

场景：概念科普 / 信息分享（混场：04 章教学串＝培训课）  
brand_kit：internal-teal  
拟页数：46  
技能：ppt-workbench 3.8.0

## 1. 主题（一句）

模型会回答还不等于业务落地；FDE 要全程负责把 AI 接到真实工作流里干完活，并把现场模式回灌产品——内线四品类也用同一套尺子。

## 2. 纲要（章问题链）

1. **落地问题：** 模型已经能回答，业务为什么仍可能用不好？  
2. **FDE 是谁：** FDE 负责哪些事，怎样和售前、纯咨询划清边界？四会缺一会怎样？  
3. **怎样算干完：** 「替人把活干完」用哪些门来验收？  
4. **落地怎么走：** 一条任务怎样走到可运行、可验证、可接手？Ontology Lite 与 CodeG 各管什么？  
5. **部门内线：** 智能客服 / 知识库 / 语音 / AI Coding 怎样共用同一 FDE 口径？  
6. **收口：** 今天带走什么，边界在哪里？

推进形态（科普）：要弄清的误区 → 机制拆解 → 现场/教学例子 → 适用边界。

## 3. 页脊（按页一句话，听众能听懂）

### 开场
- P01 封面：今天讲清 FDE 怎样把 AI 接到真实工作流里干完活。  
- P02 目录：五章问题 + 收口；沿一条售后教学任务串起来听。

### 01 落地问题
- P03 章入口：模型会答，业务仍可能用不好——差在哪？  
- P04 售后答复生成后，还要核对依据、权限、异常接手和实际使用。  
- P05 常见卡点：Demo 好看、口径打架、定制堆人天、任意写回、岗位名碎片。  
- P06 本册主张：缺交付所有权与语义层时，Agent 不可治理、不可验收、不可复制。  
- P07 小桥：先认清谁对「干完」负责——下一章讲 FDE。

### 02 FDE 是谁
- P08 章入口：FDE 负责什么，边界在哪？  
- P09 一句话定义：全程负责 + 写生产代码 + 回灌。  
- P10 所有权弧：discovery → scope → build → rollout → adoption/handoff → productize。  
- P11 分水岭对照：FDE / 售前 SE / 纯咨询人天。  
- P12 四会：懂技术、懂业务、能开发、能交付——现场能看见的行为。  
- P13 缺一症状：方案落不了 / Demo 无人用 / 变成顾问 / PoC 永不 Harden。  
- P14 与 TDL：FDE 写码；TDL/Strategist 管范围与价值度量、不写生产码。  
- P15 回灌是义务：无回灌的长期驻场 = 改牌外包。  
- P16 FAQ 快答：SA 默认 ≠ FDE；Demo ≠ Prod。

### 03 怎样算干完
- P17 章入口：怎样判断「替人把活干完」？  
- P18 买方买的是被采用的工作流改变，不是答题准确率。  
- P19 度量三角：采用 · 工作流指标 · eval 反馈。  
- P20 write-back：业务轨必须有经治理的写回动作。  
- P21 G1–G7 验收门一览。  
- P22 最短判据：G1 ∧ G2 ∧ G4；缺一仍是 Chatbot PoC。  
- P23 反面五种：PoC 当交付、Demo=Prod、人天冒充成功、无回灌、跳过 Discovery。  
- P24 小桥：门清楚了，下一章看一条任务怎么走完。

### 04 落地怎么走
- P25 章入口：一条任务怎样成为可运行、可验证、可接手的应用？  
- P26 过程地图：定义任务 → 实现验证 → 采用交接与回灌。  
- P27 教学任务亮相：售后政策助手（演练，非部门已上线）。  
- P28 任务完成长什么样：有依据答复 / 缺资料转人工 / 写操作另授权。  
- P29 Ontology Lite 一句到位：名词+动词+绑定+安全+版本；无语义层不可治理。  
- P30 双用途：客户域包 ∥ FDE 工作知识（≈ CodeG 对象）。  
- P31 与 CodeG：CodeG=调度/HITL/证据底座；本轨道=运营层+本体+Demo，不换栈。  
- P32 实现选择：规则 / RAG / 固定工作流 / Agent——售后例用检索+固定流+坐席审核。  
- P33 验证分层：业务结果 · 模型应用 · 工程运行。  
- P34 K-17 教学故障：沿证据修数据契约与检索规则（演练）。  
- P35 采用与交接：无原厂盯屏可运行；留下回灌候选。  
- P36 章收：机制记住三句话——门禁、本体一句、CodeG 不换栈。

### 05 部门内线
- P37 章入口：内线四品类怎样用同一套 FDE 尺子？  
- P38 双轨：外线客户 ∥ 内线业务方×四品类；成功仍看 G1–G7。  
- P39 四品类总览：智能客服 · 知识库 · 语音 · AI Coding。  
- P40 切面对照：每类「替人干完」的活、写回类别、回灌去向（不编功能清单）。  
- P41 与 CodeG：AI Coding 产品能力互补调度底座；知识库常为共用语义底座。  
- P42 内线红线：Demo≠Prod；零回灌；调参当交货；无产品 Owner 签字空转。

### 收口
- P43 带走五句：定义、四会、干完门、Ontology 一句、内线同尺。  
- P44 适用边界：本册是口径与方法科普；教学≠已实施；不推倒 CodeG。  
- P45 开放问答导航（可选停留）。  
- P46 封底致谢 / 继续阅读：拆读册 04→01–03→06；总册 proposal。
