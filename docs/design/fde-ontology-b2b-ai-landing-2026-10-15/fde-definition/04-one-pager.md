## 三句话（硬）

1. **FDE** = 嵌入客户、**discovery → production rollout → adoption/handoff 全程负责**，写生产代码，并把现场模式**回灌**成产品能力 —— **≠ 售前 SE，≠ 纯咨询人天**；配对 TDL **不写生产码**（管 SOW/ROI）。  
2. **能力** = **懂技术 + 懂业务 + 能开发 + 能交付**（四象限缺一不可）；对内统一称 FDE（美：OpenAI/Anthropic/Scale/Palantir；中：商汤已用职衔，多数驻场/交付/SA **职责同构**）。  
3. **价值** = 不是「会答题」，是「**替人把活干完**」：度量三角 = **production adoption + measurable workflow impact + eval-driven feedback**；业务轨必须含 **write-back 动作闭环**。

---

## 验收表 G1–G7（硬 · 最短 DoD）

| 门 | 过线标准 |
|----|----------|
| **G1** 采用 | 生产按设计频率使用（≠ Demo 点开） |
| **G2** 工作流指标 | 基线 → 后测 KPI 有数 |
| **G3** Eval 门 | 金标达 threshold；失败可追溯 |
| **G4** 写回/动作 | 经治理写入 SoR/工单；幂等·权限·审计 |
| **G5** Launch | 观测 / 回滚 / HITL / runbook |
| **G6** Handoff | 无原厂盯屏可运行 |
| **G7** 回灌 | ≥1 回灌候选进产品队列 |

**交货最短判据：** G1 ∧ G2 ∧ G4。缺一 = 仍是 Chatbot PoC。

## 红线（硬 · 压缩）

| # | 禁止 |
