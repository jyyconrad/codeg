CodeG = 个人工作代理台

默认像 Cowork / Work：能聊、能交办、能定时；打开代码仓库时再露出 git 级联与多 coding agent。护城河留下，门面换软。

完整 Markdown：product-spec.md · wireframes.md · scenarios.md（本页为预览合成）

功能规格 W1 工作台 W2 Composer W3 交办中 W4 审批 W5 Review W6 进阶 W7 通知 W8 Wiki S1–S6 场景 范围与指标

1. 产品定位与原则

目标用户：个人知识工作者 / 也会写代码的人。
验收故事：非开发同事只靠中文完成「调研写周报 + 定时更新」，不见 worktree/merge；开发同事仍一键回到 To-do 合并流。
  • 少模式税 — 同一 Composer；短问直聊，多步「转为交办」。
  • 交办为主 — 描述结果 → 离开 → 回来审。
  • 审批有档 — 谨慎 / 平衡（默认）/ 放开；读自动，写发删才问。
  • 交付预览优先 — Review 主视图是成果，diff 次之。
  • 非编码隐藏 git 术语 — 隔离工作区 → 待你确认 → 采纳。
  • 深度进阶露出 — @ / Canvas 非新手默认；开仓库再露 coding 全家桶。
  • 做完来找你 — 托盘 + 系统通知 + 可选频道。

必先做 / 可后做 / 不做 · 成功指标

必先做

  • Composer 统一 + 转为交办做大
  • 非编码文案层
  • 托盘 + 完成通知
  • 审批三档（默认平衡）
  • Review 预览优先
  • 改外界走计划卡
  • Wiki 最小可用
  • 进度「当前步骤」统一

可后做 / 明确不做

  • 后做：行内改、事件触发、云 worker、项目对象、插件包、Canvas 模板、热键
  • 不做：砍掉多代理深度、再叠模式、移动端假完整本机 Agent、本阶段主推企业 SSO

定性成功信号

  • 不先选模式也能完成快问 + 交办
  • 敢离开屏幕，靠通知回来
  • 非编码不见 git 词；编码路径完整
  • 平衡档不再步步点；预览能决定采纳
  • 同一天周报交办 + 开仓库改代码无需换产品
