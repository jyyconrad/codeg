# Codeg Agent 可靠性与子智能体配置改进

2026-09-19。本文记录本次实现边界，配合[标准消息存储与上下文压缩方案](codeg-agent-message-history.md)和[可选压缩分支方案](codeg-agent-compact-llm-branch.md)阅读。设计文档中的其他目标仍需按实际代码判断。

## 子智能体模型与工具

子智能体继续通过 Rig AgentRunner 执行。`subagent` 工具增加两个可选参数：

| 参数 | 行为 |
| --- | --- |
| `model_id` | 从当前会话配置的模型目录中选择，使用对应的上下文窗口；省略时继承主模型。模型仍使用当前会话的 provider 和连接配置。 |
| `allowed_tools` | 选择实际注册到子 Agent 的工具；省略时保持默认 Explore 只读工具集合，显式 `[]` 允许只返回文本。 |

示例中的模型 ID 必须替换为当前会话已配置的值：

```json
{
  "prompt": "检查缓存失效逻辑，给出文件位置和结论",
  "model_id": "configured-model-id",
  "allowed_tools": ["read_file", "grep", "glob"]
}
```

工具白名单同时约束注册工具、发送给模型的 schema 和请求预算。未知模型、未知工具或超出父会话边界的工具在子任务启动前返回错误。父会话允许时，可以显式选择写文件、编辑、Bash 和 MCP 工具；写操作沿用父会话的权限策略，Plan 模式继续限制可用工具。

子任务使用独立调用身份、取消令牌和产物目录。没有报告写入工具时，完成消息直接携带文本；启用报告工具时，报告位于该子任务自己的目录，避免复用上一次报告。主 Agent 一轮结束后，会话仍处理后台子任务的权限请求。取消后晚到的请求应被丢弃。

本次保留单个后台子任务和原有轮数上限，不增加子 Agent 并发、worktree 管理或新的权限层级。

## 消息确认与预算

Rig 的确认回调提供本次 run 的累计消息序列。保存游标依据 run 和序号向前推进；相同正文出现在不同序号时仍完整保存。重复回调不重复追加，已确认前缀发生撤回或修改则显式报错。摘要正文不通过文本前缀识别，活动摘要也不写回原始消息文件。

标准消息读取增加完整序列化往返校验，遇到当前类型无法保留的字段时停止读取并保留文件。确认消息快照在正常追加时增量更新；外部文件变化会使缓存失效。

窗口和整请求预算使用 Rig 的 token counter。预算覆盖系统内容、历史、当前输入、工具 schema 及额外注入的内置说明，并预留模型输出和安全额度。默认按软阈值触发压缩，目标保留比例与触发比例分开；最近用户轮配置参与合法切点选择。计数仍是估算，实际 provider 拒绝由下面的有界恢复处理。

## 压缩与请求恢复

摘要候选先保留为待提交状态，整请求预算检查通过且取消令牌有效后再激活。失败时保留原文与此前有效的摘要。默认无工具摘要与可选文件摘要使用一致的提示词契约；后续文件摘要会带上此前仍有效的附件正文。

首轮历史加载和摘要请求位于 turn worker，命令循环可继续接收取消。切换主模型后，下一个空闲轮次重建其上下文配置；未显式指定摘要模型时，摘要模型随主模型切换。

provider 明确返回上下文超限，并且本次请求尚未产生任何 raw stream 事件时，Codeg 可强制压缩后重试该模型请求一次。重试保留系统信息、文档、工具定义和当前输入，由原 Rig run 接着执行。已经执行的工具不会因这次恢复重新调用。已开始输出的请求、其他类型错误或第二次超限会结束当前请求。

这些调整使用 Rig 的 `CompletionModel`、流转换、memory policy 和 compactor 接口；依赖版本及既有确认消息补丁保持原样。

## 验证范围

回归集中在真实本地 HTTP 请求、完整消息写入、压缩检查点、取消与模型切换，以及子任务实际工具清单和写操作授权。模拟模型用于稳定复现边界，不调用真实 provider。最终命令和结果以本次交付记录为准。
